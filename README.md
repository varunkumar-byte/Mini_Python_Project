📦 Inventory Management System

1. Project Overview

The Inventory Management System is a Python-based project designed to manage products, stock, shopping carts, customer orders, and customer feedback.

This project helps users maintain product records, calculate inventory value, manage available stock, and visualize inventory information using graphical representations.

The project uses Python programming concepts and the Matplotlib library to generate different types of graphs.

3. Features

The project provides the following features:

1. Display Products – Displays all available products with their ID, name, price, and stock.
2. Add New Product – Adds new products to the inventory.
3. Calculate Inventory Value – Calculates the total value of available inventory.
4. Remove Product – Removes products using their product ID.
5. Add Products to Cart – Allows customers to select products and quantities.
6. View Shopping Cart – Displays selected products and total cart value.
7. Place Order – Confirms orders and automatically updates product stock.
8. Customer Feedback – Accepts feedback from customers.
9. Stock Bar Graph – Displays product stock comparisons using a bar chart.
10. Stock Pie Chart – Shows the percentage distribution of product stock.
11. Product Price Graph – Compares product prices using a line graph.

5. Python Concepts Used

The following Python concepts are implemented:

- Dictionary: Stores product information such as name, price, and stock.
- List: Stores shopping cart items.
- Tuple: Stores product ID and quantity in the cart.
- Functions: Divides the program into smaller reusable modules.
- Loops: Repeats the main menu and product selection process.
- Conditional Statements: Performs operations based on user choices.
- List Comprehension: Extracts product names, prices, and stock for graphs.
- Matplotlib: Creates graphical representations of inventory data.

7. Installation and Setup

Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/

Step 2: Install Visual Studio Code

Download VS Code:

https://code.visualstudio.com/

Step 3: Install Matplotlib

Open the VS Code terminal and execute:

pip install matplotlib

Step 4: Run the Project

Open the project folder in VS Code.

Run the following command:

python inventory.py

8. Required Library

The project uses Matplotlib for creating graphs.

Install it using:

9. Graphical Representation

The project provides three types of graphs.

A. Stock Bar Graph

Displays the available stock of different products.

B. Stock Pie Chart
